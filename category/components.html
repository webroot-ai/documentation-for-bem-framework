Component Library

Pre-built UI components using BEM methodology with SCSS.

📄️ Button

A flexible, accessible button component built with BEM methodology. The button supports multiple variants, sizes, shapes, and states.

📄️ Card

A flexible product card component designed to display content, images, and actions. It follows the BEM methodology and includes standard interaction states and modifiers.

📄️ Checkbox

A flexible checkbox component with support for different sizes, states, and descriptions following BEM methodology.

📄️ Fieldset

A flexible fieldset component for grouping form elements with support for different sizes, layouts, and states following BEM methodology.

📄️ Input

A flexible input component with support for different sizes, states, icons, and validation messages following BEM methodology.

📄️ Radio

A customizable radio button component with support for sizes, states, and group layouts.

📄️ Select

A flexible select (dropdown) component with support for different sizes, states, and validation messages following BEM methodology.

📄️ Textarea

A flexible multi-line text input component that supports various sizes, states, character counts, and floating label interactions following BEM methodology.
